# Референс — каким должен стать результат

Текущий вид — пёстрый и «кричащий»: шрифт Comic Sans, ярко-оранжевый
фон шапки, объёмные рамки у всех блоков, восклицательные знаки в
заголовках.

## К чему нужно прийти

- **Цвета** — тёплая, спокойная кофейная палитра: молочно-бежевый фон,
  тёмно-коричневый акцент, без ярко-оранжевого и без резких контрастов.
- **Типографика** — современный читаемый шрифт (system-ui, "Georgia"
  для заголовков + без засечек для текста), без теней у заголовка.
- **Меню** — карточки с ценой, а не список текстом; кнопки фильтра
  меню оформлены как аккуратные табы, а не 3D-кнопки.
- **Форма бронирования** — визуально выделена в отдельный опрятный
  блок с понятными полями, крупная кнопка отправки.
- Общий вид — уютный, «кофейный», без лишних рамок и границ, разделами
  с достаточными отступами.
