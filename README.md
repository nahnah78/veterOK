# veterOK — лендинг кофейни «Ветерок»

Одностраничный сайт кофейни «Ветерок»: hero-блок с призывом к действию, блок «О нас», меню с фильтрацией по категориям, форма бронирования столика и контакты.

Стек — чистые **HTML + CSS + JavaScript** без сборки, фреймворков и зависимостей. Проект открывается в браузере обычным двойным щелчком по `index.html`.

## О проекте

Это портфолио-работа по **редизайну** лендинга: вёрстка и стили переработаны в тёплую кофейную палитру (молочно-бежевый фон, тёмно-коричневые акценты, золото/терракота для цен), при этом полное поведение страницы — фильтр меню и отправка формы бронирования — сохранено без изменений.

## Возможности

- **Фильтрация меню** по категориям «Всё / Напитки / Десерты» — без перезагрузки страницы.
- **Форма бронирования столика** с проверкой полей (`required`), выводом подтверждения и сбросом формы.
- **Адаптивная вёрстка**: карточки меню раскладываются сеткой и сворачиваются в одну колонку на мобильных, форма растягивается на всю ширину.
- **Состояния интерактивности**: `:hover`, `:focus`, `:focus-visible`, `:disabled` у фильтров, карточек и кнопки формы.
- **Доступность**: связки `label for`/`id`, `placeholder`-подсказки, `aria-live="polite"` у результата бронирования, `lang="ru"`, `UTF-8`.
- **Локальные шрифты** Marck Script (WOFF2) с `unicode-range`, разбитые на кириллицу, латиницу и latin-ext.

## Технологии

| Технология | Для чего |
|---|---|
| HTML5 | семантическая разметка (header, main, section, footer) |
| CSS3 | CSS-переменные, градиенты, flex/grid, media-запросы, кастомные шрифты |
| Vanilla JavaScript | фильтр меню, обработка формы бронирования (без библиотек) |
| WOFF2 | локально подключённые шрифты |

## Быстрый старт

Проекту не нужны установка зависимостей, сервер или сборка.

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере (двойной щелчок или `File → Open`).

Готово — фильтры меню и форма бронирования работают на месте.
